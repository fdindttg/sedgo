API 文档

将 AI 视频生成能力集成到您的应用中。

快速开始

使用 Sedgo API，您可以轻松将 AI 视频生成能力集成到您的应用程序中。

认证方式

所有 API 请求都需要通过 API Key 进行认证。在请求头中添加以下字段：

Authorization: Bearer YOUR_API_KEY

创建视频任务

使用 POST /v1/tasks 端点创建视频生成任务：

curl -X POST https://api.sedgo.ai/v1/tasks \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "beautiful sunset over ocean",
    "model": "sedgo-fast",
    "duration_seconds": 10,
    "resolution": "1080p"
  }'

查询任务状态

使用 GET /v1/tasks/{task_id} 端点查询任务状态：

curl -X GET https://api.sedgo.ai/v1/tasks/TASK_ID \
  -H "Authorization: Bearer YOUR_API_KEY"

可用模型

  • sedgo-fast - 快速生成模型，适合快速预览
  • sedgo - 高质量模型，适合最终输出

响应格式

{
  "task_id": "task_123456",
  "status": "completed",
  "video_url": "https://api.sedgo.ai/v1/files/video.mp4",
  "duration": 10,
  "resolution": "1080p"
}
