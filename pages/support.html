常见问题

Q: 视频生成需要多长时间？

A: 视频生成时间取决于视频长度和所选模型。通常 10 秒视频需要 1-2 分钟。

Q: 支持哪些分辨率？

A: 我们支持 720p、1080p 和 4K 分辨率。

Q: 如何获取 API Key？

A: 登录后在个人中心的 API 设置中可以生成和管理您的 API Key。
